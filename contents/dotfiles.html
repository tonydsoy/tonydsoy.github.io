Download my dotfiles.

Run cd ~;git clone https://github.com/tonydsoy/dotfiles;cd dotfiles;rm -rf .git/ in the Console. This will download my dotfiles into a folder in your home directory named "dotfiles" and delete GIT artifacts.

Run cd ..;cp -r dotfiles/* ~/, this will install all of the non-config dotfiles.

Run cp -r config/* ~/.config/ to install all of the configs. Reboot your system with reboot and select Hyprland when logging in with SDDM and you should have all of my dotfiles correctly installed!
